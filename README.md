G10 Smart Trail Camera

The Smart Trail Cam (STC) is an animal aware trail camera that performs classification, analysis, and alerting of detected animals. It incorporates multiple edge nodes to perform monitoring, a 'mother' node to provide interop between edge nodes, and an Android application which receives these analyses and alerts to showcase to the user. Furthermore, the application allows configuration of edge nodes through selection of classification alerts. There are a multitude of users that utilize trail cameras including hunters, campers, wildlife monitors, and park rangers. The STC provides benefits to monitoring, protection, and analysis while utilizing new novel techniques for high classification accuracy and response time. This is accomplished through inexpensive technologies to lower cost, personalization of alerts, and use of radio communication instead of cellular devices. With these improvements on existing software, we hope to provide an efficient trail camera that provides users with the security or monitoring they are looking for.


The smart trail camera system solution consists of a trail camera, one mother node, and an android device. The trail camera is the edge device that contains a motion sensor, camera, radio transceiver, and AI module to take the image of the animal passing through, classify the animal, and send the information to the mother node. The mother node is an interop between the trail camera and mobile application on the Android device. This device holds a radio module and a bluetooth module, where the radio communication is used for the trail camera and bluetooth is for communication with the application. Lastly, the mobile application holds images for the user, allows users to choose which animals they want to see, and then alerts the user when an animal of their choice has been detected.


The edge device or trail camera is made up of a HCSR501 PiR Motion sensor, Raspberry Pi OV5647 Camera Module, Adafruit ESP32 Feather V2 board, Grove Vision AI Module V2, and Adafruit RFM95W 868 to 915 MHz LoRa Transceiver Breakout components. Components are all housed and soldered to a custom PCB created in KiCAD and manufactured by OSHPark. Image capture is triggered off of successful detection of motion by the PIR motion sensor. Image is then used by the Grove Vision AI Module V2 which completes classification of the animal inside of the image using our trained model. This model was trained using Yolov8 nano. Once classification is completed, the information is sent to the LoRa module which passes the data to the mother node. The mother node consists of an Adafruit ESP32 Feather V2 board and an Adafruit FRM95W 868 to 915 MHz LoRa transceiver breakout. Information from the edge device is passed from the LoRa module to the integrated BLE module on the Feather V2 to send to the mobile application. The mobile application takes in the information passed from both the edge device and the mother node. It will look at the information to compare the animal detected to the animals selected for the alerts chosen by the user. If there is no match, the picture could be stored somewhere in the Android device. If a match is found, the user is properly alerted and can view the image.
